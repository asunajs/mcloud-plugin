# 界面用词（给用户看的话）

> 用户不懂实现。**任何出现在界面上的字**都按这份表写。

| 不要写 | 要写 |
|---|---|
| 上游 / 上游地址 / 真上游 | **移动云盘**（"来自移动云盘" / "地址"） |
| mock / 本地 mock | （高级里才允许出现） |
| docs/xxx.md、ISO 时间戳、`state` 表、句柄、PROVISION、member/apply | 一律不出现；换成"还没登录，先贴凭据"这类人话 |
| 任务名（live-listen / session-refresh…） | 只在「高级」里出现；主界面用"自动领口令"这种说法 |
| 风险标签（记账 / 不可逆） | 只在高级里出现；主界面用"会写进你的账号" |

规则一句话：**主界面只说"你要做什么、成了没有"**；怎么做到的、打到哪个地址、动了哪张表，全在「高级」里。
