# 真机验收（照着点）

这一步**只能在你的真机上做** —— 它要打真上游、要扫真码、要花真豆。
下面把它拆成「照着点」的步骤，每步写清**看什么算过**、**不过要回报什么**。

> 本地能验的都已经验过了（`npm run all` 的 1400+ 条、`e2e-mock.sh` /
> `picks-e2e.sh` / `e2e-prize.sh` 三条 mock 全链路、11 张界面截图）。
> 这一份是**剩下那一半**。
>
> ⚠ 2026-11-26 整篇重写过：上一版还在教人 `cargo build` 起 `rust-plugin-panel`、
> 还写着「推送」「设置」两个**已经删掉**的区块、以及「最近几次」那个**已经删掉**的列表。
> 界面上现在有七块：账号 / 日常 / 兑换 / 直播 / 领奖 / 数据 / 调试。

---

## 0 · 起面板

面板是 **`panel-llrt`**（不是以前的 Rust 那套），跑起来只要一个二进制 + 一个数据目录：

```bash
# 装插件（本仓库的产物目录）
./scripts/deploy-panel.sh            # 或：npm run deploy:panel -- --restart

# 直接起（令牌自定，下面用 t）
PANEL_DATA_DIR=~/panel-3030/data \
PANEL_PLUGINS_DIR=~/panel-3030/plugins \
PANEL_BIND=127.0.0.1:3030 \
~/panel-3030/panel
```

**看什么算过**：

1. `curl -s http://127.0.0.1:3030/readyz` 回 `{"ok":true,"plugins":8,"tasks":…}`；
2. 打开面板 → 左侧出现**「插件界面 → 移动云盘」**（点它就是插件页，嵌在面板里）；
3. 插件页顶栏印着版本号，与 `mcloud.panel.json` 里的 `version` 一致。

**不过要回报什么**：`readyz` 的原文、侧栏有没有那个入口、顶栏版本号。

## 1 · 登录（扫码）

界面 → **账号** → 「添加账号」→ 页签「扫码」。

**看什么算过**：

1. 二维码**真的显示出来**（不是空白框）；
2. 手机 App 扫 → 手机上点确认 → 界面**自己**变成「已登录 1x\*\*\*\*xx」；
3. 账号卡出现一条，可以「刷新 / 编辑 / 设置 / 停用 / 移除」。

**不过要回报什么**：卡在第几步、界面上的原话、面板日志里 `[mcloud]` 那几行。

---

## 2 · 登录（另外几种）

同一个弹窗里还有四个页签：**电脑短信 / 手机短信 / 账密 / 凭据**。

**看什么算过**：

- **电脑短信**：选 Windows/macOS → 填手机号 → 发码 → 填码 → 登录成功
  （这条拿的是 PC 端那套凭据，与手机端不是同一份）；
- **手机短信**：填手机号 → 发码 → 填码 → 登录成功。⚠ 这一页**没有** Windows/macOS 之分
  （用户原话：「手机端哪来的 macOS 和 Windows」）；
- **账密**：填手机号 + 密码 → **一个请求就完事**；
- **凭据**：把 `Basic …` 那串贴进去 → 直接落库。

**注意**：只有短信那一步会出现"分步"（等的是**你**）。账密/凭据不该有分步。

---

## 3 · 日常（真跑一次）

界面 → **日常** → 「现在跑一次」。

**看什么算过**：

1. 按钮变成「跑着呢 Ns」，右侧「运行日志」一行一行往下走；
2. 跑完出现**每个号一颗胶囊**：「1x\*\*\*\*xx 7 项好了、2 项没成、7 项跳过」——
   点它可以看那个号的每一步；
3. 没成的那些行是**黄的**、写的是人话（不是 `code=…`）；
4. 顶栏「上次」那行会更新成这次的时间。

**⚠ 重点看**：结果对不对 —— 签到/领取那几步有没有真的生效（去 App 里核一下）。

**不过要回报什么**：胶囊那一行的原话 + 任意一条"没成"的原话（截图最好）。

---

## 4 · 兑换（**干跑**，不花豆）

界面 → **兑换** → 「读一次」拿到奖品清单 → 从「要换什么」里选一件 → 「现在试一次」。

**看什么算过**：

1. 顶部那行写着「离这一场还有 X · 每天 10 点 · 压整点前 10ms 发」；
2. 点「现在试一次」之后，结果里**明确有一句「一枪都没发」**；
3. 「奖品清单」出现真实奖品与余量（可兑/不可兑分得开）；
4. 面板日志里**没有** `exchangeV3` 这一条请求。

**⚠ 这一步是安全的** —— 干跑只读清单、查余额、预热、取题解滑块，到"只差下单"就停。

---

## 5 · 兑换（**真抢**，会花豆 —— 想清楚了再做）

1. 「添加计划」：选账号 + 选目标 + 填一个**最近**的整点（比如现在 14:20 就填 `15`）；
2. 到点前 1 分钟盯着「兑换」页；
3. `hh:59:40` 那行字应该变成「正在抢兑窗口里」；
4. 整点过后能看到这一趟的记录：`压整点前 10ms 发` + 每个账号的 `离第一枪 +Nms`。

**看什么算过**：豆真的少了 / 奖品真的到了，且**只发了一枪**。

| 现象 | 说明什么 |
|---|---|
| 抢到了 | 一切正常 |
| 没抢到，但只发了一枪 | 正常的抢兑失败（手速/网络），不是 bug |
| **发了两枪以上** | **小时闸失效** —— 这是最严重的，立刻回报 |
| 界面停在「正在抢兑窗口里」很久 | 自旋卡住 —— 回报面板日志与当时时刻 |

## 6 · 直播

界面 → **直播** → 贴口令 → 「贴进去领取」。

**看什么算过**：四态结论（`200108` / `200112` / `200118` / 未分类）各自对应人话，
而不是错误码；「口令池」里那几条的状态会跟着变。

## 7 · 领奖

界面 → **领奖** → 选账号 → 点某一件的「领取」→ 手机上收短信 → 填验证码 → 「确认领取」。

**看什么算过**：

1. 进「领奖」自己读一次，列出**所有市场的**待领取；每行有奖品名 / 市场 / 过期时间 / 脱敏手机号；
2. 点「领取」后弹窗**没有滑块图、没有要你填像素的格子** —— 只有验证码那一格；
3. 几秒内手机收到验证码；弹窗写「验证码已发到 1x\*\*\*\*xx」；
4. 填码 → 「确认领取」→ 提示「已领取：…」→ 列表少一件（**不用点刷新**）；
5. 面板日志里只有「读到 N 件 / 验证码已发 / 已领取」，**没有** jwttoken、cookie、
   deviceId、验证码原文或摘要。

**不要做的事**：不要连续点「重新发送」（60 秒本地闸 + 上游 1001 限流）；
没收到短信先等一分钟，再点「重新发送」（会换一道滑块新题）。

## 8 · 趣玩AI（**这一条是现在最想验的**）

界面 → **数据** → 「趣玩AI 赢好礼」那张卡 → 「日常」跑一趟（或「调试」页只跑这一族）。

**看什么算过**（卡上/日志里三种之一）：

| 日志那一句 | 含义 | 下一步 |
|---|---|---|
| `「AI助手」做完了（回读已翻位）` | **成了**：服务端认这一句 | 可以接抽奖、再接别的工具 |
| `「AI助手」已上报，服务端还没认 —— …` | 点了、也聊了，但 `isComplete` 两次回读都没翻 | **说明灵犀对话不算那件任务** ⇒ 要换动作，先抓一轮"在 App 内做那件任务"的包 |
| `做「AI助手」那一步没成：…` | 动作链断在某一段（换票 / 邮箱登录 / 拿鉴权 / 对话） | 看冒号后面那一段 |

**⚠ 抽奖默认是关的**（花的是你自己的次数），卡上那个「自动抽奖」开关打开才会抽。

---

## 9 · 调试页（测新族用）

界面 → **调试**。

**看什么算过**：

1. 六族开关都在，**云手机默认关**（它会在你云机里装应用）；
2. 「用哪个账号」是**单选**（一次只跑一个号）；
3. 勾一族 + 选一个号 → 「只跑这个号」→ 日志里只有那一族，其它族各一行「这次不跑」；
4. **它不看账号设置里的开关与停用**：把那族在「设置」里关掉，这里勾上照样跑；
   跑完那个开关**还是关着**（调试不是"帮你打开"）。

## 回报模板

```text
步骤 N：
  期望：…
  实际：…
  界面原话/截图：…

```

面板日志：面板页 →「日志」（可按插件筛），或 `tail -f` 起面板那个终端。
