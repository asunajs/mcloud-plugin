# 界面截图（阶段 ②-6 的产物）

用 `node scripts/shots.mjs <面板地址> <令牌> [输出目录]` 生成。
脚本会起一个 headless 浏览器、设好面板的会话 cookie、打开插件页，
然后**逐个区块**截一张。

## 这几张图是干什么用的

静态测试能钉住「id 对得上」「七个菜单项」「没有『高级』开关」，
但**钉不住**「它看起来是不是还是乱七八糟」—— 而后者才是用户的原话：

> 界面完全搞不懂，文字一大堆，按钮点哪个都不知道

所以这几张图是「重做之后到底长什么样」的证据。

## 与旧版的对照

| | 旧版 | 这一版 |
|---|---|---|
| 布局 | 七张卡片平铺 | 菜单栏 + **一次一块** |
| 第一眼看到 | 七张卡，不知道先看哪张 | 一行大字回答那个区块的核心问题 |
| 按钮文案 | 「只验证」「换票」「推进一步」「算一次」「现在探一次」 | 「现在跑一次」「贴进去领取」「扫码登录」 |
| 藏东西 | 有「高级」开关 | **没有** —— 连"设置"那一页都没有（F-068：那些口子是搭测试环境用的） |
| 一次点击 | 推进一步，要点十几次 | **跑一次就是一次** |
| 读数来源 | 一个区块一个接口（各有各的错误状态） | **一个**聚合接口 |
| 文字量 | 接口返回值原样铺在页面上 | 读数按「用户会问的问题」组织 |

⚠ 原来还有一张 `07-settings.png`（「设置」那一页），**已删** —— 那一页在 F-068 里
整个去掉了，留着图会让人以为界面上还有它。

⚠ 截图时库里的账号是**造出来的假账号**（对着 mock 上游跑，见 `scripts/e2e-mock.sh`），
不是真号：卡片上那个设备串和凭据都是 mock 的。要重截：

```bash
./scripts/e2e-mock.sh ../rust-plugin-panel/target/release/plugin-panel 18899
# 判据：账号页要有 1 个以上账号，否则卡片那一段看不到
node scripts/shots.mjs http://127.0.0.1:18899 e2e-mock-token docs/shots
```

⚠ 第二十九轮起，这套界面**不再自带配色**：它引主面板的 `/css/theme.css` 与
`/css/components.css`（按钮、卡片、徽章、弹窗、字段全是面板那套组件），
深浅色跟着面板走（`boot.js` 读面板存在 localStorage 里的主题名）。
所以这几张图**看起来应该和面板本身是一套**，而不是另有一副长相 —— 这正是要检查的点。
